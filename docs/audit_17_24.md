# Teaching prerequisite audit: chapters 17–24

Reviewed November 12, 2026. Scope: each chapter's beginner teaching, compact summaries, worked example, four core exercise contracts/examples/hints, and independent lab requirements. This is a prerequisite and teaching-depth review, not a claim that tests can certify comprehension.

The replacement teaching is authored in `content/teaching_17_24.py`. Examples use different names and data from the assessed functions. They explain components rather than complete a practice or lab solution. Executable examples have explicit expected output; multi-step examples include a walk-through. Local framework and shell illustrations are explicitly local-only.

## Validation and limits

- All standalone Python examples in this module are checked for syntax and expected stdout independently. Parent integration also runs them in the bundled browser interpreter.
- Framework snippets and terminal/YAML illustrations require the stated local environment and are not executed in Pyodide. A structural CI example explicitly requires official checkout/setup actions before it is runnable; it is not presented as a complete ready-to-copy workflow.
- No actual network service, learner repository, production identity provider, or deployment is created by this content. The lab remains independent work.
- Teaching now introduces required vocabulary before combined examples. This review cannot establish that every learner finds every explanation sufficient; comprehension prompts and observed attempts should guide further teaching improvements.
